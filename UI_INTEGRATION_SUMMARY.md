# 🎯 Резюме: Интеграция парсера спецификаций в интерфейс

## ✅ Что было сделано

### 1. API Endpoints

Добавлены новые endpoint в `app/routers/api/documents.py`:

#### `POST /api/documents/{document_id}/parse-specifications`
- Парсинг спецификаций документа
- Параметр `format`: `json` или `excel`
- Возвращает путь к созданному файлу

#### `GET /api/documents/{document_id}/specification-summary`
- Получение сводной информации о спецификациях
- Возвращает количество страниц и список спецификаций

### 2. Обновление шаблонов

#### `app/templates/document_detail.html`
- Добавлена кнопка **📋 Спецификации** в шапку страницы
- Добавлена панель спецификаций с возможностью сворачивания
- Добавлены функции JavaScript:
  - `showSpecificationPanel()` — показать панель
  - `hideSpecificationPanel()` — скрыть панель
  - `renderSpecificationSummary()` — отобразить сводку
  - `parseSpecifications(format)` — экспорт в JSON/Excel

#### `app/templates/documents.html`
- Добавлена кнопка **📋** в таблицу документов
- Добавлена функция `quickParseSpecifications()` для быстрого парсинга

## 🎯 Как использовать

### Способ 1: Через страницу документа

1. Откройте документ (`/documents/{id}`)
2. Нажмите кнопку **📋 Спецификации**
3. Просмотрите сводную информацию
4. Нажмите **📄 Экспорт в JSON** или **📊 Экспорт в Excel**
5. Файл сохранится в `output/specifications/`

### Способ 2: Через список документов

1. Откройте список документов (`/documents`)
2. В строке нужного документа нажмите кнопку **📋**
3. Подтвердите экспорт
4. Файл сохранится в `output/specifications/`

---

## 📊 Форматы вывода

### JSON
- Структурированные данные
- Подходит для программной обработки
- Содержит таблицы, строки, метаданные

### Excel
- Несколько листов:
  - **Сводка** — общая информация
  - **Спецификация_стрN** — каждая таблица
  - **Все_спецификации** — объединённая таблица
- Удобно для ручного редактирования

## 🔧 API Использование

### Пример запроса

```bash
# Получить сводку спецификаций
curl -X GET "http://localhost:8000/api/documents/1/specification-summary" \
  -H "X-Session-Key: your_session_key"

# Парсинг в JSON
curl -X POST "http://localhost:8000/api/documents/1/parse-specifications?format=json" \
  -H "X-Session-Key: your_session_key"

# Парсинг в Excel
curl -X POST "http://localhost:8000/api/documents/1/parse-specifications?format=excel" \
  -H "X-Session-Key: your_session_key"
```

### Пример ответа

```json
{
  "status": "success",
  "document_id": 1,
  "document_name": "Спецификация.pdf",
  "format": "excel",
  "output_path": "output/specifications/Спецификация_specifications.xlsx",
  "message": "Спецификации успешно экспортированы в Excel"
}
```
