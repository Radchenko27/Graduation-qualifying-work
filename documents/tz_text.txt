2 ВВЕДЕНИЕ  
Программный продукт, разрабатываемый в рамках данной работы, 
представляет собой цифровой сервис, предназначенный для строительных 
организаций. Он представляет собой учетную систему с личным кабинетом, 
обеспечивающая удобное взаимодействие между сотрудниками строительной 
организации.  
Основная область применения приложения — обработка строительной 
документации и отчетности. Данное web-сервис предоставляет пользователям 
возможность создавать проекты, прикреплять необходимую документацию, а 
также обмениваться информацией с другими пользователями. Приложение 
ориентировано на частные строительные организации, позволяя им 
обрабатывать техническую строительную документацию и обмениваться ее 
между инженерно -техническими работниками.  
1 Основания для разработки  
Тема разработки: «Автоматизированная система обработки данных 
технической строительной документации».  
Основанием для разработки является задание на выпускную 
квалификационную работу, подписанное руковод ителем выпускной работы и 
утверждённое заведующим кафедрой ИУ5 МГТУ им. Н.Э. Баумана 1 7 октя бря 
2025 года , протокол заседания кафед ры № 3 от 17 октября 202 5 г. 
2 Назначение разработки  
Назначением разработки является создание веб -сервиса 
«Автоматизированная система обработки технической строительной 
документации», представляющего собой специализированную систему для 
учёта документации и извлечения данных из нее. Основной целью является 
обеспечение удобства взаимодействия между инженерно -техническими 
3 работниками. Web -сервис предназначен для инженерно -технических 
работников, которые могут создать проект с документацией, делится им, 
обрабатывать в нем документацию, а также обмениваться проек тами с другими 
пользователями. Также они могут использовать фильтры для поиска проекта по 
различным параметрам и делиться им с другими инженерно -техническими 
работниками. К каждому проекту есть возможность прикрепить набор 
документов. Также предусмотрены м етоды их обработки: классификация  
страниц, постраничный анализ и т. д.  Для чертежей предусмотрен следующий 
функционал: расчет элементов чертежа, составление смет  и т.д. 
Эксплуатационное назначение заключается в обеспечении стабильной работы на 
ПК. Web -серв ис будет работать по модели клиент -сервер, где серверная часть 
построена на REST -архитектуре с использованием фреймворка FastAPI . База 
данных для хранения информации о пользователях, проектах и товарах будет 
работать на PostgreSQL. Таким образом, «Автомати зированная система 
обработки данных технической строительной документации» предназначена для 
создания удобного и эффективного инструмента для инженерно -технических 
работников, который оптимизирует процесс обмена строительной 
документации, ее классификации и распознавание.
