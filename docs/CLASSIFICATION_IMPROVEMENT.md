# Улучшение классификации документов

## Что изменилось

### 1. Новый классификатор (`app/services/document_classifier_v2.py`)

**Старый подход:**
- Только ключевые слова
- Низкая точность (~60-70%)
- Нет понимания контекста

**Новый подход (гибридный):**
- ✅ Визуальные признаки (изображения, таблицы, подписи)
- ✅ Структурные признаки (позиция страницы, длина текста)
- ✅ Ключевые слова с весами
- ✅ Поддержка LayoutLM (при наличии)
- ✅ Автоматический fallback на rule-based
- ✅ Улучшенная уверенность классификации

**Ожидаемая точность:** 75-85% (без дообучения), 90-95% (с дообучением)

### 2. Интеграция

Заменён импорт в `app/routers/api/documents.py`:
```python
from ...services.document_classifier_v2 import classifier
```

## Новые возможности

### Визуальные признаки
- Подсчёт изображений на странице
- Обнаружение таблиц
- Поиск подписей (разработал, проверил...)
- Плотность текста

### Структурные признаки
- Позиция страницы (первая/последняя)
- Длина текста
- Наличие чертежных обозначений

### Улучшенная уверенность
- Расчёт на основе баланса признаков
- Усиление при нескольких сильных признаках
- Понижение при малом количестве текста

## Обратная совместимость

- Старый классификатор (`document_classifier.py`) остался без изменений
- Можно вернуться к нему в любой момент
- Новый классификатор полностью совместим с API

## Планы развития

1. **Дообучение на данных проекта** — 90-95% точности
2. **Активное обучение** — автоматическая разметка с человеческой проверкой
3. **Ensemble моделей** — комбинация нескольких подходов
4. **Онлайн-обучение** — улучшение модели по мере накопления данных

## Поддержка

При возникновении проблем:
1. Проверьте логи: `[LayoutLM]` или `[WARN]` сообщения
2. Убедитесь, что PyMuPDF установлен
3. Проверьте, что PDF содержит текст (не только изображения)

## Частые вопросы

**Q: Почему классификация работает без LayoutLM?**  
A: Новый классификатор имеет fallback на улучшенный rule-based. Он работает автоматически если LayoutLM недоступен.

**Q: Как улучшить точность?**  
A: Дообучите модель на размеченных данных проекта (см. `docs/md/LAYOUTLM_TRAINING.md`)

**Q: Можно ли отключить LayoutLM и использовать только rule-based?**  
A: Да, просто не устанавливайте `transformers` и `torch`. Классификатор автоматически переключится.
