# Автоматическая классификация страниц PDF документов

## Обзор

Система автоматически анализирует загружаемые PDF документы и классифицирует **каждую страницу** по одной из 5 категорий:

1. **Титульник** (`title`) - титульный лист, обложка
2. **Чертеж** (`drawing`) - рабочие чертежи, планы, разрезы
3. **Схема** (`scheme`) - схемы (структурные, функциональные, кинематические)
4. **Спецификация** (`specification`) - ведомости, спецификации, таблицы материалов
5. **Другое** (`other`) - всё остальное

## Категории страниц

| Категория | Описание | Ключевые слова |
|-----------|----------|----------------|
| `title` | Титульный лист | министерство, утверждаю, согласовано, разработал, проверил, стадия, листов |
| `drawing` | Чертеж | чертеж, черт., конструктивные решения, АБВГ., обозначение, привязка, оси |
| `scheme` | Схема | схема, структурная, функциональная, принципиальная, алгоритм, блок-схема |
| `specification` | Спецификация | спецификация, ведомость, материалы, оборудование, позиция, поз., наименование |
| `other` | Другое | - |

## Как это работает

### Шаг 1: Загрузка PDF

При загрузке PDF файла система:
1. Извлекает текст с каждой страницы
2. Анализирует содержимое по ключевым словам
3. Определяет тип содержимого (текст, таблица, изображение)
4. Сохраняет классификацию в базу данных

### Шаг 2: Классификация

Для каждой страницы:
- Подсчитываются совпадения ключевых слов по категориям
- Выбирается категория с наибольшим количеством совпадений
- Рассчитывается уверенность классификации (0.0 - 1.0)
- Определяется тип содержимого

### Шаг 3: Сохранение

Результаты сохраняются в таблицу `document_pages`:
- `document_id` - ссылка на документ
- `page_number` - номер страницы (с 1)
- `category` - категория страницы
- `confidence` - уверенность (0.0 - 1.0)
- `content_type` - тип содержимого
- `page_metadata` - дополнительная информация (JSON)

## Алгоритм классификации

### Ключевые слова по категориям

**Чертежи:**
- `чертеж`, `чертежи`, `черт.`, `лист`, `лист №`
- `схема`, `план`, `разрез`, `сечение`, `вид`
- `АБВГ.`, `обозначение`, `привязка`, `оси`

**Спецификации:**
- `спецификация`, `ведомость`, `материалы`
- `оборудование`, `позиция`, `поз.`, `№ поз.`
- Табличные данные (много строк с колонками)

**Расчёты:**
- `расчет`, `расчёт`, `вычисление`
- `нагрузка`, `сопромат`, `бетон`, `арматура`
- `коэффициент`, `прочность`, `деформация`

**Разрешительная документация:**
- `разрешение`, `согласование`, `утвержден`
- `лицензия`, `сертификат`, `акт`, `протокол`

### Формула уверенности

```
confidence = min(0.3 + (количество_совпадений * 0.1), 0.95)
```

- Минимальная уверенность: 0.3
- Максимальная уверенность: 0.95
- Если текста мало (< 10 слов): уверенность 0.5

## API Endpoints

### Загрузить документ с классификацией

```bash
curl -X POST http://localhost:8000/api/documents/ \
  -H "X-Session-Key: YOUR_SESSION_KEY" \
  -F "file=@document.pdf" \
  -F "name=Проект здания" \
  -F "project_id=1" \
  -F "category=working_drawings" \
  -F "auto_classify=true"
```

**Ответ:**
```json
{
  "id": 5,
  "project_id": 1,
  "name": "Проект здания",
  "category": "working_drawings",
  "page_count": 15,
  "file_path": "minio://documents/1/document.pdf"
}
```

### Лог классификации

В логах сервера будет:

```

DEBUG: Created drawing АБВГ.00001.001
DEBUG: Created drawing АБВГ.00001.002
DEBUG: Created drawing АБВГ.00001.003
```

## Ограничения

1. **Только PDF** - другие форматы не классифицируются
2. **Текстовые PDF** - сканированные изображения требуют OCR (не реализовано)
3. **Кириллица** - лучше работает с русским текстом
4. **Сложные макеты** - может ошибаться на нестандартных документах

## Примеры использования

### Пример 1: Проект здания

**Документ:** "Проект жилого дома" (20 страниц)

**Результат:**
- Страницы 1-5: Чертежи (основной проект)
- Страницы 6-10: Чертежи (архитектурные решения)
- Страницы 11-15: Спецификации (материалы)
- Страницы 16-20: Расчёты (конструктивные)

**Автоматически создано:**
- 2 чертежа (стр. 1-5, стр. 6-10)
- 1 спецификация (стр. 11-15)
- 1 расчёт (стр. 16-20)

### Пример 2: Разрешительная документация

**Документ:** "Разрешение на строительство" (5 страниц)

**Результат:**
- Все страницы: Разрешительная документация
- Уверенность: 0.85-0.95

**Автоматически создано:**
- Нет чертежей (категория permits)

## Отладка

### Включить подробный лог

В `app/main.py` добавьте:
```python
import logging
logging.basicConfig(level=logging.DEBUG)
```

### Проверить классификацию вручную

```python
from app.services.document_classifier import classifier

with open('document.pdf', 'rb') as f:
    content = f.read()

classifications = classifier.classify_pdf_pages(content)
for c in classifications:
    print(f"Стр. {c.page_number}: {c.category} ({c.confidence:.2f})")
```
