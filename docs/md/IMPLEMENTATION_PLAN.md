## Парсинг PDF и извлечение данных для смет

### Структура обработанного JSON

Пример из `processed/03-23-ОГР01.1-ЭОМ1.1-Изм.1_processed.json`:

```json
{
  "metadata": {
    "file_name": "03-23-ОГР01.1-ЭОМ1.1-Изм.1.pdf",
    "page_count": 157,
    ...
  },
  "text": {
    "0": "Страница 0 текст...",
    "1": "Страница 1 текст...",
    ...
  }
}
```

### Подход к извлечению данных

1. **Поиск спецификаций:**
   - Искать таблицы с материалами
   - Выделять колонки: Название, Марка, Кол-во, Ед.изм.

2. **Распознавание паттернов:**
   ```python
   # Пример паттерна для поиска материалов
   patterns = {
       'cable': r'(ПРГнг|ППГнг|ПуГПнг)\s*\d×\d[\d,]+\s*мм²',
       'fixture': r'(светильник|светодиодный)',
       'device': r'(розетка|выключатель|датчик)',
   }
   ```

3. **Извлечение из таблиц:**
   - Разбиение текста на строки
   - Определение границ таблицы
   - Парсинг колонок

### Рекомендации по улучшению парсинга

**Вариант 1: На основе правил (текущий подход)**
```python
def extract_materials_from_pdf(json_data: dict) -> list[dict]:
    """
    Извлечь материалы из обработанного PDF
    """
    materials = []
    
    for page_num, text in json_data['text'].items():
        # Поиск таблицы спецификации
        if 'спецификация' in text.lower() or 'ведомость' in text.lower():
            # Парсинг строк таблицы
            lines = text.split('\n')
            for line in lines:
                # Извлечение материала
                material = parse_material_line(line)
                if material:
                    materials.append(material)
    
    return materials
```

**Вариант 2: Использование OCR + ML**

- OpenCV для детекции таблиц
- Tesseract для OCR (если текст не извлекается)

**Вариант 3: Ручной ввод с автодополнением**
