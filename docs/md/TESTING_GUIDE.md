## Возможные проблемы и решения

### Проблема 1: "Материалы не найдены в файле"

**Причина:** Паттерны парсера не совпадают с форматом текста

**Решение:**
1. Проверить содержимое JSON файла:
   ```powershell
   Get-Content processed\...\_processed.json | Select-String -Pattern "спецификация" -Context 2
   ```
2. Добавить новые паттерны в `app/utils/pdf_parser.py`

### Проблема 2: "Требуется аутентификация"

**Причина:** Cookie не отправляются

**Решение:**
1. Убедиться, что `credentials: 'include'` в fetch запросах
2. Проверить CORS настройки в `app/main.py`

### Проблема 3: "Файл не найден"

**Причина:** Неправильный путь к JSON файлу

**Решение:**
- Использовать относительный путь от корня проекта
- Проверить существование файла: `ls processed/`
