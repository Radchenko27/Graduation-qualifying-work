# Использование автоматической классификации из интерфейса

## 🎯 Быстрый старт

### Загрузка документа с автоматической классификацией

1. **Открой страницу документов:**
   ```
   http://localhost:8000/documents
   ```

2. **Нажми кнопку** `+ Загрузить документ`

3. **Заполни форму:**
   ```
   ┌────────────────────────────────────────┐
   │ Файл:          [Выберите файл...]     │
   │ Название:      Чертежи фундамента     │
   │ Проект:        ЖК "Солнечный"         │
   │ Категория:     ▼ Другое (автоопределение) │
   │                                        │
   │ ☑ 🔍 Автоматическая классификация страниц  │
   │   - Проанализирует содержимое страниц│
   │   - Определит категорию              │
   │   - Создаст чертежи                  │
   │                                        │
   │          [Загрузить]    [Отмена]      │
   └────────────────────────────────────────┘
   ```

4. **Выбери PDF файл** с компьютера

5. **Убедись, что включён чекбокс** "🔍 Автоматическая классификация страниц"

6. **Нажми** `Загрузить`

## 📊 Что происходит при загрузке

### Шаг 1: Загрузка файла
```

```

### Шаг 6: Успех
```
✅ Документ загружен! Автоматическая классификация завершена.
```

## 🔧 Настройки

### Автоматическая классификация (ВКЛ)

**Рекомендуется для PDF документов**

- ✅ Категория определяется автоматически
- ✅ Чертежи создаются автоматически
- ✅ Быстрее и удобнее

### Автоматическая классификация (ВЫКЛ)

**Для случаев, когда нужно вручную указать категорию**

- ⚠️ Категория указывается вручную
- ⚠️ Чертежи не создаются
- ⚠️ Медленнее

## 🐛 Отладка

### Просмотр логов

В терминале, где запущен сервер:
```bash
uvicorn app.main:app --reload
```

При загрузке документа увидишь:
```
DEBUG: Classifying 15 pages of document 'Чертежи'
DEBUG: Auto-detected category: working_drawings (votes: {'working_drawings': 10, 'specifications': 5})
DEBUG: Classification complete. Found 2 drawings
DEBUG: Created drawing АБВГ.00001.001
DEBUG: Created drawing АБВГ.00001.002
```

### Если классификация не работает

1. **Проверь, установлен ли PyMuPDF:**
   ```bash
   pip list | grep PyMuPDF
   ```

2. **Установи если нет:**
   ```bash
   pip install PyMuPDF
   ```

3. **Перезагрузи сервер:**
   ```bash
   # В терминале Ctrl+C, затем:
   uvicorn app.main:app --reload
   ```

4. **Попробуй загрузить PDF с текстом** (не сканированное изображение)

## ❓ Частые вопросы

### Почему не определяется категория?

- PDF может быть сканированным изображением (требуется OCR)
- Слишком мало текста на страницах
- Документ не соответствует шаблонам

**Решение:** Выбери категорию вручную

### Можно изменить категорию после загрузки?

Да, через БД или API:
```python
# В консоли Python
from app.db import db
from app import crud

session = db.get_db()
crud.Documents.update(session, document_id, {"category": "new_category"})
```

### Как посмотреть созданные чертежи?

1. Открой страницу проекта
2. Перейди на вкладку "Чертежи"
3. Там будут все автоматически созданные чертежи

### Можно отключить автоклассификацию навсегда?

В `app/templates/documents.html` измени:
```html
<input type="checkbox" id="autoClassify" name="auto_classify" value="true" checked>
```
на:
```html
<input type="checkbox" id="autoClassify" name="auto_classify" value="true">
```
(убери `checked`)
